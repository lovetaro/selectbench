# Safety suite — on-targets (Proteins of Interest)

This directory holds the **on-target** receptors for SelectBench's **Safety**
suite — the 5 Proteins of Interest (`parp1`, `jak2`, `braf`, `fa7`, `5ht1b`).
The shared **off-target** anti-target panel lives in
[`../safety_targets/`](../safety_targets/).

The directory name `standard_docking_benchmark` is historical; for selectivity
these are simply the Safety on-targets. For the full Safety-suite layout, the
on/off pairing, box conventions, and the `htr1b_agonist` / `5ht1b` exclusion
rule, see [`../README.md`](../README.md).
